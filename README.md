# Тренировки

Дневник тренировок для Макса и Ани: подходы с таймером отдыха и подсказками по весам, дневник питания и веса, кардио, замеры, прогресс. Работает без интернета и синхронизируется через Supabase.

- **Android:** скачай `Trainer.apk` из раздела [Releases](../../releases/latest) и установи.
- **Windows:** открой сайт приложения в Chrome или Edge и нажми значок «Установить» в адресной строке.

## Устройство

| Папка | Что там |
| --- | --- |
| `web/` | само приложение: `index.html`, `app.js`, `programs.js` (программы тренировок), `config.js` (адрес и публичный ключ Supabase) |
| `android/` | Android-обёртка (Capacitor), APK собирается автоматически на GitHub |
| `supabase/schema.sql` | таблица и правила доступа: каждый видит только свои записи |
| `.github/workflows/build.yml` | при каждом изменении собирает APK (Releases) и обновляет сайт (Pages) |

Поменять упражнения: правь `web/programs.js`, после загрузки изменений новая версия соберётся сама.
